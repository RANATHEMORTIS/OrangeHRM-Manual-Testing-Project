# OrangeHRM Manual Testing Project

## Project Overview

This project demonstrates end-to-end Manual Testing performed on the OrangeHRM Human Resource Management System (HRMS).

The objective of this project is to validate the functionality, usability, and business workflows of OrangeHRM by designing and executing detailed test cases across multiple modules.

---

## Application Under Test

Application Name: OrangeHRM

Application Type: Human Resource Management System (HRMS)

Website:
https://opensource-demo.orangehrmlive.com/

---

## Project Objectives

* Validate application functionality
* Verify business requirements
* Identify and report defects
* Improve application quality
* Ensure user workflows function correctly
